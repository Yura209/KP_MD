# СтройМаркет

Учебный интернет-маркетплейс строительных материалов и товаров для дома на Node.js, Express и PostgreSQL. Покупатель собирает общую корзину из нескольких магазинов; продавцы обрабатывают только собственные части заказа; администратор подключает магазины и управляет доставкой.

## Локальный запуск

1. Установите Node.js LTS и PostgreSQL.
2. Создайте пустую базу `stroy_market` либо используйте настроенную в `.env`.
3. Скопируйте `.env.example` в `.env` только для новой конфигурации. Задайте реквизиты PostgreSQL. Не публикуйте `.env`.
4. Выполните `npm install`, затем `npm run db:init`.
5. Запустите `npm start` и откройте `http://localhost:3000`.
6. При первом открытии `/account.html` с этого компьютера создайте учётную запись администратора с паролем от 12 символов. Форма доступна один раз. Администратор создаёт магазин и учётные записи продавцов; покупатели регистрируются самостоятельно.

Миграция сохраняет пользователей, магазины, категории и товары прежнего прототипа. Старые таблицы заказов и оплат переименовываются в `legacy_*`, новые записи создаются в нормализованной схеме. Повторный запуск `npm run db:init` идемпотентен. Перед переносом приложения на внешний сервер настройте защищённый HTTPS, резервное копирование, постоянное хранилище сессий и подтверждение первого администратора.

## Разделы приложения

- `/` — список активных магазинов.
- `/store.html?store=<id>` — каталог выбранного магазина, поиск, фильтры, сортировка, расчёт упаковок, избранное и сравнение.
- `/cart.html` — отдельная общая корзина и оформление заказа из нескольких магазинов.
- `/account.html` — кабинет покупателя, продавца или администратора; покупателю доступны история заказов, демо-оплата и подтверждение получения.
- Продавец может добавить изображение товара ссылкой или загрузить PNG, JPEG либо WebP до 2 МБ.
- `/api/health` — проверка соединения; `/api/stores`, `/api/categories`, `/api/products` — публичный каталог.

## Модель данных

Основные таблицы: `users`, `stores`, `seller_stores`, `categories`, `units`, `products`, `carts`, `cart_items`, `orders`, `order_parts`, `order_items`, `payments`, `delivery_events`, `order_status_history`, `reviews`, `return_requests`, `favorites`, `comparisons`, `notifications`, `audit_log`, `app_settings`. Внешние ключи и ограничения целостности описаны в `database/schema.sql`; тестовые категории и магазины — в `database/seed.sql`.

В заказах сохраняются снимки артикула, названия, единицы, цены и количества. Остаток не уменьшается при добавлении в корзину; он проверяется при оформлении и повторно резервируется транзакцией после подтверждения продавцом.

## Ограничения учебной версии

Демо-оплата только меняет статус и не списывает реальные деньги. Сессии хранятся в памяти Node.js и завершаются после перезапуска. Email-уведомления и внешние перевозчики не подключены; журнал уведомлений находится в кабинете. Тариф доставки учитывает выбранную зону, массу, суммарный объём и максимальную сторону упаковки; маршрутизация не выполняется. Промышленный запуск требует отдельной проверки информационной безопасности и обработки персональных данных.
